HOW IT WORKS

Three checks, explained.

Each rule runs separately, so the project is easy to test and extend.

01

IP address

Checks whether the link uses a numeric IPv4 address instead of a domain name.

HOST CHECK
02

URL length

Flags addresses longer than 75 characters. Long links are not always malicious, but they can hide their destination.

LENGTH > 75
03

Keyword patterns

Looks for configured terms such as “login-verify” and “account-update”.

PROJECT DESIGN

Small components. Clear responsibilities.

The Flask route handles the request, the facade coordinates analysis, and separate strategy classes apply the checks. This demonstrates the layered architecture, Facade Pattern and Strategy Pattern from the project blueprint.
